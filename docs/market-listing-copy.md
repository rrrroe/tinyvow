# Tiny Vow 应用市场宣传文案

## 最简洁版

Tiny Vow 是一款本地优先的手机使用管理工具，用「约定 + 鼓励」帮你更温和地减少分心、建立习惯。

你可以为常用应用设置每日、每周或每月限额，超额后获得清晰提醒；也可以把阅读、学习、运动等应用加入鼓励分组，按使用时长获得积分和奖励。所有核心数据默认保存在本机，让自律更可持续，也更安心。

## 稍详细版

Tiny Vow 不是简单粗暴的锁机工具，而是一套围绕「约定、反馈、奖励」设计的手机使用管理应用。

你可以把容易分心的应用加入 CONTROL 分组，设置每日、每周或每月使用限额。超过约定后，Tiny Vow 会通过温和的全屏阻断提醒你停一下，把注意力带回真正重要的事情。

对于希望多做的事情，比如阅读、学习、健身、创作，你可以创建 ENCOURAGE 分组。使用这些应用时，Tiny Vow 会按时长累计积分，并支持目标奖励、兑换奖励、成就记录和连续达成追踪，让好习惯也有即时反馈。

Tiny Vow 坚持本地优先：分组、积分、奖励、使用历史、主题偏好等核心数据默认保存在你的设备上。你可以导出本地备份，也可以随时管理自己的数据。

适合想减少刷手机、控制娱乐应用、培养阅读学习习惯，或者希望用更柔和方式管理自己数字生活的人。

## 更详细版

Tiny Vow 是一款本地优先的数字习惯管理应用。它不把自律设计成惩罚，而是用「约定 + 鼓励」帮助你和手机建立更清晰的边界。

### 管住容易分心的应用

把短视频、社交、游戏等应用加入 CONTROL 分组后，你可以为它们设置每日、每周或每月使用限额。Tiny Vow 会统计同一分组内应用的总使用时长，超过约定后弹出全屏阻断提醒，让你及时意识到自己已经越过边界。

如果确实有临时需求，也可以通过奖励库存使用加时包、周期通行证或紧急解锁，在保留记录的前提下灵活调整，而不是一味强制拦截。

### 鼓励真正想多做的事情

Tiny Vow 同时支持 ENCOURAGE 鼓励分组。你可以把阅读、学习、运动、写作、工具类应用加入其中，按使用时长获得积分，并为目标达成设置奖励。

积分可以用于兑换内置奖励或自定义奖励，成就系统会记录累计积分、兑换积分、达成天数和连续达成等进度。相比单纯限制，Tiny Vow 更希望帮你看见自己正在变好。

### 看见每天的变化

统计页会整理每日归档、趋势、热力图、应用排行和分组表现，帮助你复盘真实使用情况。你可以看到哪些应用占用了时间，也可以看到哪些好习惯正在稳定发生。

对于特殊使用场景，Tiny Vow 还支持微信读书双源时长口径，可按配置在阅读时长和本机前台时长之间选择更合适的统计方式。

### 本地优先，重视隐私

Tiny Vow 的核心数据默认保存在本机，包括分组、积分、兑换历史、奖励库存、使用归档、自定义主题和本地备份。应用不会把你的使用记录作为默认行为上传到远端服务。

你可以导出本地数据报告或可恢复备份，也可以在需要时清理本地数据。敏感权限只用于实现使用统计、超额提醒和本地通知等核心功能。

### 适合这些人

- 想减少短视频、社交、游戏等娱乐应用的无意识使用。
- 想建立阅读、学习、运动、创作等长期习惯。
- 不喜欢粗暴锁机，希望用更柔和、更可解释的方式管理手机。
- 重视本地数据和隐私，希望核心记录保存在自己的设备上。
- 想通过积分、奖励、成就和统计反馈，让自律变得更容易坚持。

Tiny Vow 希望成为你和手机之间的一份小小约定：少一点被动消耗，多一点主动选择。
