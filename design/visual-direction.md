# Tiny Vow 视觉方向

本文档用于约束 Tiny Vow 后续主题与 UI 调整。目标不是复刻某个参考 App，而是把参考图里的高级感转译成适合 Tiny Vow 的 Android / Compose 设计系统。

## 核心气质

Tiny Vow 应该像一个安静、可靠、带一点温度的本地使用管理工具。

- 简约：界面元素少而准，避免堆叠装饰。
- 优雅：用留白、字重、层级、轻阴影建立质感。
- 高级：低饱和、低对比、稳定节奏，不依赖强烈渐变和大片彩色。
- 耐看：每天打开都不刺眼，不追求一眼惊艳。
- 本地可信：视觉上要像用户自己的小账本、小仪表盘，而不是营销型产品。

推荐内部命名：`Quiet Premium / Paper Wellness`。

## 参考图取舍

### Alma 风格：作为首页首屏主参考

取用：

- 暖白纸感背景。
- 白色大卡片。
- 极轻柔阴影。
- 深橄榄绿作为主色。
- 柠檬绿只用于关键进度。
- 深棕或近黑文字。
- 中心圆环指标作为首屏视觉锚点。
- 卡片之间有足够留白。

不取用：

- 完整营养 App 语义。
- 过多 emoji / 贴图式图标。
- 底部中间大加号导航。
- iOS 状态栏和交互细节。

### Habit Dots 风格：作为底部导航主参考

取用：

- 底部导航低存在感。
- 背景融入页面，不做重玻璃悬浮。
- 图标为主，文字轻量。
- 选中态用主题色和小图标块表达。
- 未选中态使用低对比灰。
- 整体安静、工具感强。

不取用：

- 过度可爱化图标。
- 过淡导致不可读的文字。
- 与 Tiny Vow 无关的游戏化贴纸感。

### 洞察页风格：作为统计页参考

取用：

- 白底、少卡片、强数据层级。
- 使用条形、时间分布、排行榜表达数据。
- 图表颜色克制，重点数据突出。
- 大数字和标题清楚分层。

不取用：

- 过多高饱和 App 颜色同时出现。
- 信息过密导致阅读压力。

### KakaoBank 风格：作为分组卡片参考

取用：

- 大块分组卡片。
- 稳定的卡片间距。
- 简洁标题和关键数字。
- 少量色块建立分类。

不取用：

- 金融账户隐喻。
- 大面积强彩色列表作为默认首页主视觉。

## 色彩原则

主题应以中性色为主，语义色为辅。

### 默认主题方向

建议默认主题：`Paper Olive`

- 页面背景：暖白、米灰、纸感白。
- 卡片背景：接近纯白，但不要刺眼。
- 主文字：深棕黑或暖黑。
- 次级文字：暖灰。
- 主色：深橄榄绿。
- 进度强调：柠檬绿或柔和黄绿。
- CONTROL：克制暖珊瑚 / 赤陶色，用于警示和限制。
- ENCOURAGE：橄榄绿 / 鼠尾草绿，用于鼓励和成长。
- 图表辅助色：低饱和蓝灰、雾绿、浅赭、灰紫。

### 禁止方向

- 不要让界面被紫蓝渐变主导。
- 不要使用大面积糖果色。
- 不要让 CONTROL 和 ENCOURAGE 同时大面积抢色。
- 不要依赖彩虹式图表色板。
- 不要用纯白背景 + 纯黑文字造成生硬感。
- 不要把主题做成只有一个色相的单调配色。

## 形状与阴影

### 圆角

- 首页主卡片：24dp 到 28dp。
- 普通卡片：18dp 到 24dp。
- 小标签 / 胶囊：999dp。
- 图标容器：14dp 到 18dp。
- 不建议继续扩大到 32dp 以上，除非是非常明确的主视觉模块。

### 阴影

- 阴影要柔，不要重。
- 默认卡片优先使用白色表面 + 极轻边线 + 低透明阴影。
- 不要让卡片看起来像一层层浮在页面上。
- 首页首屏可以有轻微漂浮感，普通列表应更平。

## 字体层级

- 首页核心数字可以大，但数量要少。
- 页面标题使用清楚的中大字号，不要过度 hero 化。
- 卡片标题使用中等字重。
- 正文保持轻、短、可扫读。
- 次级说明用低对比灰，不要和主信息抢层级。
- 中文界面避免过密行高，保留呼吸感。

## 首页方向

首页应该像 Tiny Vow 的每日仪表盘。

首屏结构建议：

1. 顶部区域：
   - 左侧或中间显示 Tiny Vow 标识。
   - 右侧使用积分胶囊或轻量状态入口。
   - 避免拥挤的顶部按钮。

2. 今日总览主卡：
   - 使用白色大卡片。
   - 中心放今日守约分 / 平衡分圆环。
   - 只放一句简短解释。
   - CONTROL 和 ENCOURAGE 只作为两个轻量摘要出现。
   - 减少复杂背景渐变和装饰图形。

3. 提示卡：
   - 权限、提醒、建议使用轻量白卡。
   - 文案短，动作明确。
   - 不要用强警告色铺满卡片。

4. 分组摘要：
   - 分组卡片保持清楚、稳定。
   - 重点展示进度、限额、今日用量。
   - 不要让每个分组都像一张独立海报。

## 底部导航方向

底部导航采用 Habit Dots 参考图方向。

- 保持 4 个主入口：首页、统计、奖励、我的。
- 使用固定底栏，不做中间大加号。
- 背景使用页面同色或接近白色。
- 顶部分割线极轻，或完全无边线。
- 选中态：
  - 图标使用主色。
  - 可以使用很淡的圆角色块承托图标。
  - 文字使用主色或较深文字。
- 未选中态：
  - 图标使用灰色。
  - 文字更轻。
- 底栏高度要克制，不要显得厚重。

## 统计页方向

统计页要像“洞察”，不是装饰型战报。

- 大数字用于关键结论。
- 图表优先清楚，其次才是漂亮。
- 同一屏不要出现过多高饱和颜色。
- 热力图、趋势图、Top Apps 要使用统一图表色板。
- 免费锁定状态要克制，不要像广告位。
- 分享图可以更有表现力，但仍保持同一主题语言。

## 奖励和成就方向

- 奖励页可以比首页稍微活泼，但不能破坏整体高级感。
- 内置奖励图标允许可爱，但容器和排版要克制。
- 成就等级用精致徽章感，不做强烈游戏 UI。
- 积分余额和兑换动作要清楚，避免过多装饰。

## 主题系统方向

自定义主题不应只让用户手动调三种颜色。后续应考虑改成：

- 先选择风格：纸感、冷静、温暖、深色、低对比。
- 再微调主色和语义色。
- 提供实时预览：
  - 首页主卡。
  - 分组卡片。
  - 统计图表。
  - 阻断 overlay。

内置主题应少而精。每套主题都要有明确风格，不要只是换三种柔和彩色。

### 主题框架 v2

每套主题先定义 9 个基础角色，再由代码推导 Material 3、图表、导航、卡片和状态色。

- `background`：页面底色。决定应用的整体温度，必须低饱和，不能比卡片更抢眼。
- `surface`：卡片和弹层底色。默认接近白，但可以带一点纸感、瓷感或雾感。
- `inkStrong`：标题、关键数字、强状态。不能用纯黑，需带主题色倾向。
- `ink`：正文和普通信息。比 `inkStrong` 轻，但仍保证可读。
- `inkMuted`：说明、副标题、次级数字。低对比但不发灰发脏。
- `base`：主题主色。用于导航选中、主按钮、主题标识、页面核心强调。
- `progressAccent`：进度亮色。只用于圆环、进度条和关键完成感，不大面积铺底。
- `control`：约定色。用于约定分组、超出、阻断、风险提醒，应该克制但明确。
- `encourage`：投入色。用于投入分组、积分、目标达成和正向反馈，应比约定色更稳定、更轻松。

推导规则：

- 卡片容器优先由 `surface + neutralAccent` 推导，不直接拿主色铺满。
- `controlContainer` 和 `encourageContainer` 必须是低饱和浅容器，用于首页左右翼和分组背景。
- 导航选中态使用 `base`，未选中态使用 `inkMuted` 推淡。
- 图表色板从 `base / progressAccent / control / encourage` 扩展，最多 10 色，不做彩虹。
- 状态色不新增一套独立颜色：危险来自 `control`，成功来自 `encourage`，提示来自 `progressAccent` 与 `control` 的混合。
- 主题预设少而精；新增主题必须先说明风格，不允许只是改三种色值。

当前三套候选预设：

- `瓷白森庭 / Porcelain Grove`：冷静、清透、偏现代健康工具。瓷白背景、深青墨色、森林投入色。
- `亚麻琥珀 / Linen Amber`：温暖、纸感、偏生活账本。亚麻底、琥珀主色、低饱和陶土约定色。
- `莲雾石墨 / Lotus Graphite`：柔和、细腻、偏情绪陪伴。莲雾背景、石墨紫墨色、柔绿投入色。

## 优先改造顺序

1. 重做主题 token 和默认主题。
2. 改首页首屏总览卡。
3. 改底部导航。
4. 调整普通卡片圆角、阴影、边线。
5. 调整统计页图表色和卡片层级。
6. 改主题设置页预览方式。
7. 最后再统一奖励页、成就页、阻断 overlay。

## 实现注意事项

- UI 文案继续走字符串资源，不在 Compose 里硬编码用户可见文案。
- 不改变现有业务逻辑和数据模型。
- Compose 里复杂计算不要增加。
- 主题改动要同步阻断 overlay 和统计分享图。
- 页面要检查中文和英文下的文字长度。
- 修改 UI 后至少运行 `testChinaDebugUnitTest`；涉及资源或构建配置时运行 `assembleDefaultDebug`。
- 视觉改动完成后建议人工真机检查首页、统计页、底部导航、阻断 overlay。
